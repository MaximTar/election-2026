# Controlled English glossary

The Russian release `ru-release-v1` is authoritative. This glossary controls the translation only and introduces no scientific definitions or states.

| Russian concept | English term | Usage boundary |
|---|---|---|
| сценарий | scenario | A conditional calculation, not a forecast or an estimate of the true result |
| правило расчёта | calculation rule | Preserve the particular rule being discussed |
| опорный интервал | reference interval | A single Cedar bin when that is the source meaning |
| опорное окно / диапазон | reference window / range | Use reference window for the iStories control and reference range in ordinary prose |
| опорная область | reference area | Do not imply that its observations are verified as honest |
| область поддержки | model support | The target precincts for which the prescribed comparison exists, not political support |
| УИК с определившимся сравнением | supported target precincts | A/B/C applicability, not party supporters |
| применимость | applicability | Undefined does not mean zero |
| остаток | residual | Never silently replace with party share or fraudulent votes |
| знаковый остаток / отклонение | signed residual / signed deviation | Negative values remain possible |
| фокальная партия | focal party | The party singled out by the calculation |
| доля партии | party share | Name the denominator where the source does |
| действительные голоса | valid votes | Preserve the valid-vote denominator |
| недействительные бюллетени | invalid ballots | Unknown values are not zero |
| выданные бюллетени | ballots issued | Not automatically interchangeable with ballots cast |
| зарегистрированные избиратели | registered voters | Preserve electorate denominator |
| интенсивность выдачи | issuance intensity | Ballots issued / registered voters |
| геометрия явка × результат | turnout/result geometry | Descriptive visual structure; exact coordinate labels take precedence |
| компонента | component | A statistical component, not a causal population |
| подогнанная компонента | fitted component | A result within the chosen model |
| центр компоненты | component center | Not automatically a national counterfactual party share |
| принадлежность к компоненте | component membership | Within-model membership, not honesty/fraud probability |
| порог принадлежности | membership threshold | Threshold-only states reuse the fitted model |
| ковариационный эллипс | covariance ellipse | Component geometry, not an honesty/fraud boundary |
| ядро | core | Distinguish descriptive visual concentration from a selected model component |
| «честное ядро» | "honest core" | Keep quotation marks and external attribution; not the project's precinct classification |
| «хвост кометы» | "comet tail" | Visual descriptive expression, not a universal formal object |
| чувствительность | sensitivity | Tested specification changes, not a confidence interval |
| версия источника / данных | source version / data version | No correctness ranking based on model outputs |
| реконструкция | reconstruction | Does not imply exact recovery of unavailable upstream code |
| адаптация | adaptation | Explicit project choices in applying a source construction |
| репликация | replication | Use exact replication only where the Russian source makes that claim |
| контрфактический | counterfactual | Preserve the conditional interpretation |
| аномалия / статистическая аномалия | anomaly / statistical anomaly | Does not establish a violation |
| подгонка | fitting / fit | Parameter fitting is distinct from tuning to a desired political number |
| исключение по одному региону | leave-one-region-out | Influence sensitivity, not a label of a bad region |
| процентный пункт | percentage point | Abbreviated pp in compact labels |
| УИК | precinct election commission (UIK) | Keep UIK identifiers; UIKs is the English plural |
| ТИК | territorial election commission (TIK) | Keep TIK identifiers; TIKs is the English plural |
| ДЭГ | remote electronic voting (DEG) | Keep DEG where the source abbreviation is used |
