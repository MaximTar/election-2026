# Reproducibility materials v1

This release publishes scientific code, fixed contracts/configuration, project-derived input views, frozen results, source documentation, and verification tools. It is not a self-contained archive of every third-party raw input.

The initial release gate was BLOCKED because exact Zhizhin snapshot redistribution/retrieval had not been established. The user subsequently authorized a publication policy: retain provenance and hashes, but do not redistribute source-origin raw snapshots. This resolves the materials-release gate without claiming permission to mirror those snapshots or guaranteed historical retrieval.

Scientific scope: the paper primary universe (87,736 UIKs, 84 regions, 2,818 official TIKs), primary/S1/S2a/S2b, 1,620 A/B/C/D calculation cells, and 445 external-method research states. Only 444 external states are publication eligible. Together the static API exposes 2,064 PUBLIC states. The iStories LS state is retained only in explicitly labelled historical research records, never in the publication API. CARD_ONLY descriptions have no project numeric result.

A/B/C are ten-party conditional scenarios. D is a focal-party conditional scenario. iStories returns a scenario share. Cedar returns signed excess divided by observed focal votes. Novaya 1D returns a fitted component center. Novaya 2D returns fitted centers and model membership. These are different quantities and cannot be averaged into a truth estimate. Missing/undefined values are never zero.

G evidence is a bounded methodological/requirements-level NO-GO with mathematical counterexamples. There were no implemented scientific G fits, no real election rows passed through G, and no executed synthetic G benchmark family. The release packages the requirements and analytical witness artifacts, not older empirical-run descriptions. It does not assert that every possible anomaly-aware method is impossible.

No new model calls, fits, states, parameter choices, or scientific outputs were produced for this release. Original code hashes are retained, including the archived external qualification source. No article draft, UI, session capture, private key, or conversation export is included.

Historical manifests may reference custody/governance/scratch files outside this dependency release. They document historical bindings, not a claim that every previous experiment is mirrored. `manifest.json` is the authoritative inventory of included release material and external requirements. Original sealed vault/key material is excluded. Exact revealed result records are supplied for verification instead of publishing private custody keys.

No project-wide reuse license has yet been selected. External data retain their own source/rights status. Project-derived views are distinct from the source-origin raw snapshots.

One original authorization metadata path is a local symlink to its v1 predecessor. Both immutable hash-identical paths are supplied as ordinary archive files, with the original alias target recorded. No historical file or link was changed.

The old raw-download manifest contains local network diagnostics and is not mirrored. `source_snapshot_metadata.json` is an explicitly derived NON_MODEL provenance projection preserving original URLs, acquisition times, sizes, hashes and the original manifest hash. Original local artifacts were not edited.
